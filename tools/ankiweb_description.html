AnkiHelper: fix the card you're studying in one key, with your own one-click moves. This add-on is the Anki side of AnkiHelper, a free desktop app that turns notes you dictate or paste while studying into well-formed cards (following Andy Matuschak's "How to write good prompts", Michael Nielsen's "Augmenting long-term memory", SuperMemo's "Twenty rules of formulating knowledge" and Bloom's taxonomy), using an AI agent you already have: Claude Code, Codex, Gemini CLI or OpenCode. What the add-on does
  • A ✎ AnkiHelper button on the review screen, next to Edit: talk about and fix this card, optimize it, or see its history.
  • F on the review screen: work on the card you're studying. Press a move (Word it better, Say it simply, Make it a scenario, Split this, Versions) or say what you want changed, paste ideas or pictures, and add new cards with one click, including real cloze cards. OK keeps the new version (Edit → Undo brings the old one back).
  • 🎬 Make it a scenario: turns a card into a coding task built from real open-source code (Mastodon, Discourse, GitLab…), asked the way LeetCode asks: just enough context, examples of the expected behavior, and never a hint at which method to use. You write the code; the back has the real answer and a link to the file.
  • ✨ Versions: 3 or 4 other ways to ask the same thing (why, scenario, compare, reverse, cloze, interview), climbing from recall to real use. When a card is about code, each version shows that code on its front.
  • Your own moves: ⭐ Save as move turns a conversation into a reusable one-click move; 🎓 Teach updates a move after you correct its result. Moves remember the results you kept, and once a day AnkiHelper suggests new moves from your conversations. You always see every card; nothing runs in bulk.
  • ✨ Optimize this card: send a card you already have to AnkiHelper's preview to get a cleaner version plus deeper cards, and pick the ones you want. Or tick Optimize makes versions, without opening Preview: the card goes straight to the next batch with all its versions, and you keep reviewing.
  • Cards that remember where they came from: every card made by a move, Versions or the F window knows the card it was made from, so when one confuses you later, press F and ask.
  • History of this card (right-click while reviewing): your original note and pictures, the other cards made from it, and the alternative versions you were offered, with one click to switch.
  • An AnkiHelper button in the top bar opens the app: inbox, card preview, moves and settings (including which model your agent uses).
  • Cards are formatted to remember: the main point first, key terms in bold, highlighted code, and Obsidian-style callouts, tables and highlights.
Requirements
  • The AnkiHelper app installed on the same computer: see the install guide. Run ankihelper install-addon once so the add-on can find it.
  • AnkiConnect for batches.
  • One AI agent CLI (Claude Code, Codex, Gemini CLI or OpenCode), logged in.
Rewriting works on cards with exactly two fields (a question and an answer); existing cloze and image occlusion cards are never rewritten, though AnkiHelper can add new cloze cards. Linux and Windows are supported; macOS support in the app is written but untested. Source, issues and feedback: github.com/da5ater/AnkiHelper
